# Panel de Control y Sistema de Inicio de Sesión

Este proyecto consiste en una interfaz web que cuenta con una pantalla de inicio de sesión y un panel de control con un diseño moderno. Su objetivo es presentar información de manera organizada mediante tarjetas, tablas y diferentes secciones visuales.

El diseño utiliza colores oscuros, fondos claros, efectos visuales y elementos adaptables a diferentes tamaños de pantalla.

## Características principales

- Inicio de sesión: formulario para ingresar usuario y contraseña.

- Validación de acceso: verifica las credenciales introducidas por el usuario.

- Recordar usuario: permite guardar el nombre de usuario en el navegador.

- Mensajes de error: muestra una notificación cuando las credenciales son incorrectas.

- Panel de control: interfaz visual con tarjetas, tablas y paneles informativos.

- Diseño responsivo: adapta la pantalla de inicio de sesión a dispositivos con diferentes tamaños.

- Efectos visuales: animaciones, transiciones y efectos al interactuar con los botones.

## Tecnologías utilizadas

**HTML5:** estructura de las páginas web.

**CSS3:** estilos, colores, distribución de elementos, animaciones y diseño responsivo.

**JavaScript:** validación del formulario, almacenamiento local y redirección entre páginas.

## Instalación y ejecución

Descarga o clona el repositorio desde GitHub.

Descomprime los archivos si descargaste el proyecto en formato ZIP.

Abre la carpeta del proyecto en Visual Studio Code.

Verifica que los archivos HTML, CSS y JavaScript estén correctamente vinculados.

Abre el archivo de inicio de sesión en un navegador web.

Introduce las credenciales de prueba configuradas en el código para verificar el funcionamiento del prototipo.

# Credenciales de prueba

Estas credenciales son únicamente para pruebas. No se recomienda utilizar este método en un sistema real, ya que las credenciales almacenadas en JavaScript pueden ser visibles para los usuarios.

## Almacenamiento de datos

El proyecto utiliza localStorage para recordar el nombre de usuario cuando se activa esa opción y sessionStorage para guardar una marca de sesión durante la pestaña del navegador.

Este almacenamiento es del lado del cliente y no sustituye un sistema de autenticación seguro en un servidor.
